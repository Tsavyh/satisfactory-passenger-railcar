# Vagón de pasajeros · Prueba para dos

**Viaja acompañado. La locomotora se ocupa de conducir.**

- Dos plazas en un mismo vagón, con cámara exterior y velocímetro independientes.
- Modelo de vagón personalizado.
- Utiliza el comportamiento ferroviario normal cuando es posible; los pasajeros no conducen ni acceden a la carga.

> **Versión experimental:** todavía no se han validado las dos plazas con jugadores reales, la desconexión, el guardado/carga ni los servidores dedicados. No tiene revisión independiente completa. Usad una partida de prueba con copia de seguridad, no una partida personal.

**[Descargar la versión de prueba para Windows / Steam](https://github.com/Tsavyh/satisfactory-passenger-railcar/releases/tag/v0.1.16-study30)** · [English](README.md) · [Compilación](BUILDING.md)

Requiere Satisfactory Steam CL 517554 y SML 3.12.0. Todos los jugadores deben usar exactamente esta versión. Con el juego cerrado, extrae `TsabsPassengerWagon` en `FactoryGame/Mods/`, retirando antes el vagón anterior de esa carpeta. No mezcles versiones.

La [versión 0.1.15](https://github.com/Tsavyh/satisfactory-passenger-railcar/releases/tag/v0.1.15) sigue disponible. El código propio está bajo [MIT](LICENSE); los recursos visuales derivados del juego no están cubiertos por esa licencia. [Hashes de las entradas](SOURCE-MANIFEST.json).
